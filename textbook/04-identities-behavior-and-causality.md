# 04 恒等式、行为与因果：哪些结论不能直接推出？

> 编写于 2026-10-03。所有数字与模型参数均为教学假设。现实统计口径与模型口径分别说明，不将自编算例当成实证估计。

## 一个正确等式，为什么可能被用来得出错误结论？

你可能见过三句话：“储蓄等于投资”“政府赤字等于私人盈余”“多存一点钱会使经济更富有”。

第一句在限定的核算范围内可以是恒等式；第二句遗漏国外部门时可能错误；第三句则需要解释收入、投资和生产怎样变化。把它们接在一起，并不会自动形成因果理论。

本章完成第一篇的核心任务：从共同账户推导部门收支，再给账户加入行为规则，看为什么同一恒等式能够容纳不同结果。读完后应能完成部门平衡计算，解释事前意愿与事后结果，并辨认政策结果、政策原因及反事实。

前置为 [第 3 章](03-balance-sheets-and-transactions.md)。只需简单代数；每个符号都从数字例子引入。

## 1. 从总产出到部门收支：先把范围固定

### 1.1 本章的简化经济

设一个经济体当期国内生产总值为 1,000。全部使用同一期、同一价格口径的金额，最终用途为：

| 项目 | 金额 |
| --- | ---: |
| 私人消费 C | 600 |
| 私人投资 I，包括存货变化 | 150 |
| 政府购买 G，包括政府消费与投资 | 220 |
| 出口 X | 100 |
| 进口 M | 70 |

各项相加：

    Y = C + I + G + X − M
      = 600 +150 +220 +100 −70
      = 1,000

Y 表示国内总产出及与其对应的本章收入口径。减去进口，是因为 C、I、G 等购买分类可能已经含有国外生产内容，需把非本国产出扣除；不是因为进口本身“没有用”或自动伤害福利。

现实 GDP 的支出与收入估计会有统计差异。本章先假设没有统计误差，也不讨论跨境初次收入、转移、资本转移、折旧和其他复杂调整。BEA 的账户框架区分生产、收入、资本与对外账户，使用真实数据时要恢复这些项目。[BEA：Measuring the Economy](https://www.bea.gov/sites/default/files/methodologies/nipa_primer.pdf)

### 1.2 税收和政府购买分别指什么？

本章 T 表示私人部门向政府的净经常支付，简化为税收减政府向私人的经常转移。若没有转移，T 就是税收。模型暂不另列利息或其他收支。

G 是政府对当期产品与服务的购买，包含政府投资；不把给家庭的转移支付再计入 G，否则可能与家庭随后消费重复计算。

政府收支余额写成 T−G，正数是盈余，负数是赤字；反过来 G−T 把赤字记为正。这里的余额是模型定义，不是可以不经调整就套到任一国家财政现金报表的字段。

### 1.3 私人储蓄不是居民存款

把家庭、企业和银行放进本章的私人部门，假设没有跨境收入差异。私人可支配收入为 Y−T，扣除私人消费后得到私人储蓄 S：

    S = Y − T − C

企业留存收入也属于私人储蓄的一部分，因此这里的 S 不是只看住户，更不是“银行存款增加”。

设 T＝200，则：

    S = 1,000 −200 −600 = 200

私人部门虽然储蓄 200，也进行了实际投资 150，所以可以向其他部门净提供的资金为 S−I＝50。其金融表现可以是增加金融资产或减少负债；具体工具要另查金融账户。

## 2. 一步步推导三部门平衡

从产出恒等式出发：

    Y = C + I + G + (X − M)

两边减去 C 和 T：

    Y − C − T = I + G − T + (X − M)

左边就是 S，再减去 I：

    S − I = (G − T) + (X − M)

这个等式的每一项都是同一时期的流量：

- S−I：私人部门储蓄减投资，即本模型的私人净贷出。
- G−T：政府赤字，以正数表示。
- X−M：净出口；本模型排除了其他跨境经常项目，因此也对应简化的对外经常收支。

代入刚才的数字：

    私人净贷出 = 200 −150 = 50
    政府赤字   = 220 −200 = 20
    净出口     = 100 −70 = 30
    50 = 20 +30

如果把每个部门的盈余都记为正，国外部门的盈余要从国外视角计算，为 M−X＝−30：

    私人余额 +政府余额 +国外余额 = 0
    50 +(−20)+(−30) = 0

一个部门净贷出，必然对应其他部门合计净借入。这是选择完整边界后各项相互抵销的结果，并没有说明哪个部门最先改变了行为。

### 2.1 政府储蓄与政府余额也不能混用

因为 G 包含政府投资，T−G 是本模型的整体收支余额。若把政府消费与投资分开，政府储蓄是经常收入减经常支出，之后还要减政府投资等项目才能得到净贷出。

因此，不能一边把 G 定义成政府消费加投资，一边又把 T−G 无条件叫作“政府储蓄”。私人部门的 S−I 与政府部门的相应余额，必须在投资处理上对齐。

### 2.2 这个等式还没有解释什么？

它没有决定 GDP 是 1,000 还是 800，没有决定税收政策、企业投资和进口如何反应，也没有决定银行以什么条件贷款。它约束的是这些结果必须彼此一致。

对 MMT 而言，部门收支是重要分析起点；对任何使用相同账户边界的理论，它也是必须满足的一致性要求。能够写出等式，不等于已经给出了收入决定模型。

## 3. 四组数字，纠正“政府赤字等于私人盈余”

| 情景 | 政府赤字 G−T | 净出口 X−M | 私人净贷出 S−I | 国外部门余额 M−X |
| --- | ---: | ---: | ---: | ---: |
| A：政府赤字、对外逆差 | 70 | −40 | 30 | 40 |
| B：政府平衡、对外顺差 | 0 | 30 | 30 | −30 |
| C：政府盈余、对外顺差更大 | −20 | 50 | 30 | −50 |
| D：政府赤字、对外逆差更大 | 70 | −90 | −20 | 90 |

每一行都满足私人、政府、国外三个余额之和为零。

情景 A 中，私人盈余只有 30，不是政府赤字的全部 70。情景 B 与 C 中，政府没有赤字，私人部门仍可净贷出。情景 D 中，政府有赤字，私人部门仍然净借入。

只有在封闭经济或相关对外余额为零等条件下，才可将本模型简化为 S−I＝G−T。若使用“非政府部门”而不是“境内私人部门”，其边界通常要包含国外部门，不能偷换名称。

### 3.1 也不能把私人盈余平均分给每个人

私人合计盈余 50，可以由家庭盈余 80、企业赤字 30、银行余额 0 组成。它不保证每个家庭收入改善，也不保证没有高负债企业。

合计余额还能掩盖规模：某些主体可能借入 500，另一些取得大量金融资产，抵销后仅剩 50。研究金融脆弱性时，必须继续查看总资产负债、期限和分布。

### 3.2 谁持有新国债，不等于谁获得全部新增净金融资产

外国投资者可以用原有本币存款购买国债，这只是把一种本币资产换成另一种，其净金融头寸未必增加。同样，境内银行买新债也不能单凭持有金额推断居民储蓄。

部门余额讨论净头寸的交易性变化，国债持有者表讨论某类资产的持有结构，两者需要通过完整金融交易连接。

## 4. 现实数据里，为什么不能直接把贸易差额代进去？

简化模型只保留货物与服务贸易。真实的**经常账户**还包括跨境初次收入和二次收入，例如投资收入以及某些经常转移；它并不等于海关货物贸易差额。

**资本账户**又不是日常财经报道里笼统所说的“资本流入”：国际收支标准中，它有较窄的定义，涉及资本转移和非生产非金融资产等。金融资产与负债交易主要在金融账户记录。IMF 的国际收支资料明确区分这些账户。[IMF：Balance of Payments 数据说明](https://data.imf.org/Datasets/BOP)

从真实部门净贷出关系入手时，应把国内各部门合计净贷出，与对外经常账户、资本账户的对应余额衔接，并处理统计误差。本章的 NX，即 X−M，只在排除其他项目的教学假设下代表相应对外余额。

具体核对顺序是：

1. 固定国家、时期、单位、居民范围与数据版本。
2. 明确政府是中央财政、一般政府还是更广的合并部门。
3. 区分储蓄、投资、净贷出以及现金赤字。
4. 恢复对外收入、转移、资本账户和统计差异。
5. 最后检查金融账户的净资产交易是否对应。

不能因为两个独立统计系统的数据没有直接相加为零，就立即声称会计恒等式失效；也不能为凑零随便删掉不方便的项目。

## 5. 储蓄等于投资，为什么仍然会出现卖不出去？

### 5.1 先看计划与实际的区别

暂时取消政府与国外部门。企业本期生产 1,000，原计划全部销售。最后家庭消费购买 760，企业计划购买的新固定资产等为 200，总计划最终购买只有 960。

剩下的 40 如果成为未售存货，就进入实际存货投资：

    实际投资 = 计划投资 200 +非意愿存货增加 40 = 240
    实际储蓄 = 收入 1,000 −消费 760 = 240
    实际储蓄 = 实际投资

这里企业没有因为等式成立就心满意足。它们可能本来不想多持有 40 存货，下一期可能减少生产、调整价格或改变采购。

**事前计划**是交易发生之前希望做什么；**事后记录**是最终发生了什么。收入核算可以使事后储蓄与投资一致，并不保证所有事前意愿已经相互匹配。

### 5.2 收入本身会参与调整

企业减少生产可能减少工资、利润和其他收入。家庭即使仍希望储蓄较大比例，也可能因收入降低而无法实现原先想要的储蓄金额。

这就是为何不能从“储蓄等于投资”推出“提高储蓄意愿一定自动提供更多资金、使投资等额增加”。需要明确投资是否响应利率、销售预期和融资条件，以及收入如何变化。

## 6. 节俭悖论：用同一模型看意愿与结果

### 6.1 先设一个能完整求解的小经济

仍为封闭经济、没有政府。价格不变，有足够闲置生产能力，私人投资 I 固定为 200。家庭与企业合并后的消费规则简化为：

    C = c × Y

c 是边际与平均消费比例，本模型中两者相同。它不是永久心理常数，只是本例设定。初始 c＝0.8。若企业不希望继续积累非意愿存货，产出与计划支出相等：

    Y = C + I = 0.8Y +200
    0.2Y = 200
    Y = 1,000

因此消费为 800，储蓄为 200。

### 6.2 所有人都希望多储蓄一点

现在将 c 降到 0.75，投资仍固定为 200。在收入暂时还是 1,000 时，计划消费降到 750，期望储蓄升到 250。计划总支出为 950，若产出未立即调整，首先可能出现额外存货。

在企业最终按较低需求调整产出的模型中：

    Y = 0.75Y +200
    0.25Y = 200
    Y = 800

新消费为 600，实际储蓄仍为 200：

| 项目 | 初始均衡 | 收入暂未调整时的意愿 | 新均衡 |
| --- | ---: | ---: | ---: |
| 收入 Y | 1,000 | 1,000 | 800 |
| 消费比例 c | 0.8 | 0.75 | 0.75 |
| 消费 C | 800 | 750 | 600 |
| 希望或实现的储蓄 | 实现 200 | 希望 250 | 实现 200 |
| 计划投资 I | 200 | 200 | 200 |

“悖论”不是算术矛盾，而是个体行动的合计反馈：大家试图在原收入下多储蓄，支出下降却让原收入无法维持，最终没有实现更多合计储蓄。

### 6.3 为什么这不是反对任何储蓄的定律？

结论依赖投资固定、没有政府与外部需求抵销、价格与供给条件等假设。

如果消费比例变为 0.75 的同时，投资因新机会增加到 250：

    Y = 250 ÷(1−0.75) = 1,000
    S = 250

收入就不需要下降。或者引入政府，在投资仍为 200 时增加购买 50、税收暂为零，同样能使本例收入达到 1,000，私人储蓄达到 250。

这些是替代模型情景，不是自动发生的现实机制。投资为何增加、政府能否及时采购、资源能否满足，都需要另作解释。正确结论是检查总体反馈，不是要求每个家庭永远不储蓄。

## 7. 赤字增加，可能是衰退的结果

### 7.1 加入税收随收入变化的规则

现在设一个独立模型：封闭经济、价格固定、存在闲置产能，利率及其他影响暂时不变，财政有权且能够执行购买。用以下规则描述消费和税收：

    C = 0.75 × (Y − T)
    T = 0.2 × Y

消费取决于税后收入，税收为收入的 20%。投资先为 I＝100，政府购买为 G＝100。

把税收代入消费：

    C = 0.75 × (Y −0.2Y) = 0.6Y

再代入总需求条件：

    Y = C + I + G = 0.6Y +100 +100
    0.4Y = 200
    Y = 500

所以 T＝100、C＝300，政府预算平衡。

### 7.2 私人投资下降，政府什么也不改

假设企业因销售前景转差，将投资从 100 减到 60。税率、消费规则和政府购买不变：

    Y = (60 +100) ÷0.4 = 400
    T = 0.2 ×400 = 80
    C = 0.75 ×(400−80) = 240
    政府赤字 = 100 −80 = 20

观察者会看见 GDP 下降 100、赤字增加 20。不能据此说赤字造成了衰退，因为本模型的起因是私人投资下降，赤字变化由税收随收入下降产生。

这种税收随经济活动变化、无须每次新立法就改变收支的机制，是自动稳定器的一部分。它也使政府无法仅凭宣布购买金额就完全决定最终赤字。

### 7.3 政府主动增加购买，比较基准又该怎样选？

政府在投资下降后将 G 从 100 增加到 120：

    Y = (60 +120) ÷0.4 = 450
    T = 90
    C = 270
    政府赤字 = 120 −90 = 30

把三种情况列在一起：

| 项目 | 初始状态 | 投资下降，无新政策 | 投资下降，政府购买增加 20 |
| --- | ---: | ---: | ---: |
| 私人投资 I | 100 | 60 | 60 |
| 政府购买 G | 100 | 100 | 120 |
| 收入 Y | 500 | 400 | 450 |
| 税收 T | 100 | 80 | 90 |
| 消费 C | 300 | 240 | 270 |
| 私人储蓄 S＝Y−T−C | 100 | 80 | 90 |
| 私人净贷出 S−I | 0 | 20 | 30 |
| 政府赤字 G−T | 0 | 20 | 30 |

每一列都满足私人净贷出等于政府赤字，但收入分别为 500、400、450。这个恒等式本身没有在三种状态之间作选择，行为规则和冲击才完成了决定。

## 8. 从模型结果到因果结论，还差哪些条件？

### 8.1 政策前后比较会误判

与最初 500 相比，实施新政策后的 GDP 为 450，下降 50。若计算 −50÷20＝−2.5，并说财政乘数为负，就把同时发生的投资冲击也归给了财政政策。

在这个明确设定的模型里，正确反事实是“投资同样下降，但政府不增加购买”的 GDP＝400。因此政策贡献为：

    450 −400 = 50
    模型中的购买乘数 = 50 ÷20 = 2.5

这并不证明现实乘数就是 2.5。它说明反事实需要保持其他条件可比，现实中则必须用数据和研究设计支持这种可比性。

### 8.2 用赤字变化作分母，也可能换了问题

相对于无新政策情景，政府购买增加 20，但赤字只从 20 增到 30，增加 10，因为收入恢复使税收多了 10。

如果拿产出增加 50 除以赤字增加 10，会得到 5。它不是前面的“每增加一单位政府购买”的乘数，分母不同，经济含义也不同。

同理，不能把预算安排、发债金额、实际付款、GDP 政府购买混作同一政策冲击。第 15 章会进一步区分融资与执行。

### 8.3 一个合格的因果解释需要完成四步

先规定比较对象和政策冲击；再说明其他条件怎样保持或怎样变化；随后给出行为机制与计算；最后指出需要什么证据支持这些条件。

例如，若实际经济接近关键资源上限，本模型的固定价格与闲置产能假设就不适用。若央行或私人信用利差发生反应，投资固定的条件也可能不成立。发现条件不成立时，应修正模型，而不是要求现实服从等式以外的假设。

## 9. 把流量接回存量，还要处理估值

本章的净贷出是流量，通常对应金融资产净获得减负债净发生。一个部门净贷出 50，不一定意味着它按市场价值计算的净金融资产存量恰好增加 50。

假设期初净金融资产为 100，本期净金融交易增加 50，但已有证券价格变化造成净持有损失 20，其他变化为零：

    期末净金融资产 = 100 +50 −20 = 130

期末只增加 30，不能据此否认当期净贷出 50。第 3 章的存量分解在这里仍然适用。

存量—流量一致方法要求所有主体的交易和跨期余额互相衔接，但这是一套约束模型的组织方法，不会替研究者自动选择消费、投资、定价或政策规则。[Godley、Lavoie，2000](https://www.levyinstitute.org/publications/kaleckian-models-of-growth-in-a-stock-flow-monetary-framework/)

## 10. 原始资料带读：同时找账户与行为

先读 BEA 入门材料对储蓄投资账户和国外交易账户的说明。把私人储蓄、政府储蓄、投资与净贷出分别圈出，记录为什么一个预算现金数不能直接替换所有概念。

再读 Godley 与 Lavoie 的研究介绍，辨认哪些部分是保证账户衔接的框架，哪些部分是在给定冲击下模拟行为与结果。看到“模型始终平衡”，不要自动把它解释成“每一项行为假设都正确”。

如果使用实际部门余额数据，应保存发布日期和版本，并列出未能桥接的差额。一个诚实标明口径差异的表，优于一个把不相同的数字硬凑成零的表。

最后回到 [第 1 章](01-what-are-we-comparing.md)的五层分类，将“定义、恒等式、行为规则、估计结果、政策目标”分别标记。它们可以共同构成论证，但任何一层都不能替代其余各层。

## 11. 练习与参考答案

### 练习 1：从最终支出推导部门余额

某经济体 C＝500，I＝180，G＝240，X＝90，M＝110，T＝210。沿用本章全部简化假设。计算 Y、私人储蓄、私人净贷出、政府余额和国外余额，检查合计。

<details>
<summary>参考答案</summary>

Y＝500＋180＋240＋90−110＝900。

S＝900−210−500＝190，私人净贷出＝190−180＝10。

政府余额 T−G＝−30，国外余额 M−X＝20。

三部门合计＝10−30＋20＝0。也可用另一写法检查：私人净贷出 10＝政府赤字 30＋净出口 −20。

私人储蓄是 190，私人净贷出只有 10，两者相差私人投资 180。

</details>

### 练习 2：为什么仍有政府盈余下的私人盈余？

政府盈余 15，私人部门净贷出 25。本模型需要怎样的净出口？国外部门余额为多少？

<details>
<summary>参考答案</summary>

政府赤字 G−T＝−15，故 25＝−15＋NX，净出口 NX＝40。国外部门余额为 −40。

三个余额为私人 +25、政府 +15、国外 −40，合计为零。这个例子说明不能在开放经济中把政府赤字当作境内私人净贷出的唯一对应项。

但它没有证明一个国家可以任意选择净出口 40；外部需求、进口、汇率与其他国家的行为仍需解释。

</details>

### 练习 3：计划不一致时，恒等式怎样成立？

封闭经济、无政府，产出与收入为 800，消费实际为 590，企业计划实际投资为 170。剩余产品进入非意愿存货。求存货增加、实际总投资与实际储蓄，并说明下一期产出是否已由等式决定。

<details>
<summary>参考答案</summary>

计划购买为 590＋170＝760，非意愿存货增加 40。实际总投资为 170＋40＝210，实际储蓄为 800−590＝210。

恒等式成立，但企业未必愿意持续积累这些存货。下一期可能减产、降价或调整采购，也可能预期需求恢复而暂时不变。必须给出行为规则，等式本身没有决定反应。

</details>

### 练习 4：节俭悖论换一组数字

封闭经济、无政府，I＝120，C＝cY。初始 c＝0.8，之后降到 0.75，其他条件不变。计算两个均衡的收入和储蓄；若要在新消费比例下维持原收入，需要多少投资？

<details>
<summary>参考答案</summary>

初始 Y＝120÷0.2＝600，C＝480，S＝120。

新均衡 Y＝120÷0.25＝480，C＝360，S＝120。储蓄比例提高，但合计储蓄未增，收入下降 120。

若要在 c＝0.75 时保持 Y＝600，需 I＝(1−0.75)×600＝150，较原先多 30。这个结果只是条件计算，仍需解释投资为何能增加 30。

</details>

### 练习 5：辨认衰退造成的赤字

沿用第 7 节的 C＝0.75(Y−T)、T＝0.2Y，初始 I＝100、G＝100。现在 I 降为 80，政府不变。计算 Y、T、政府赤字，并解释为何不能把赤字变化直接当作主动刺激。

<details>
<summary>参考答案</summary>

Y＝(80＋100)÷0.4＝450，T＝90，赤字＝100−90＝10。

初始收入 500、税收 100、预算平衡。这里政府购买和税率均未改变，赤字来自私人投资下降引起的收入与税收变化。它包含自动稳定器的效果，但不是新增采购政策的规模。

</details>

### 练习 6：分清政策效果与观察结果

在上一题的投资 I＝80 条件下，政府把购买提高到 110。求收入、税收、赤字；相对于不加支出的反事实，计算购买乘数。若与最初收入 500 比较，会得到什么误导？

<details>
<summary>参考答案</summary>

Y＝(80＋110)÷0.4＝475，T＝95，赤字＝110−95＝15。

无新政策反事实为上一题的 Y＝450，所以政策贡献为 25，购买增加 10，模型乘数为 2.5。

若与投资下降之前的 500 比较，会看到收入仍低 25，甚至计算出 −25÷10＝−2.5。错误是把私人投资冲击与财政政策效果混在一起。

</details>

### 练习 7：三个部门能否同时净贷出？

有人提出：“国家应增加政府盈余，同时让私人部门更多净储蓄，也让国外对本国的金融净债权通过当期净交易继续增加。”在没有其他部门遗漏的本模型中，这些目标能否都表现为正余额？

<details>
<summary>参考答案</summary>

不能。完整的私人、政府与国外部门余额合计为零，三者不能同时为正。要实现其中两者的正余额，第三者必须承担相应负余额，或必须承认原分类遗漏了部门或交易。

这只能说明目标组合的会计不一致，尚未说明应放弃哪个目标。选择仍需结合资源、分配、外部条件与政策价值判断。

</details>

## 12. 第一篇综合作业：审阅一页宏观简报

下面是一份故意混合正确数字和错误推断的教学简报：

> 某经济体本期 C＝600、I＝150、G＝220、X＝100、M＝70、T＝200。政府赤字为 20，因此私人部门只能新增净金融资产 20。居民存款增加 8，说明私人储蓄只有 8。政府多发债 20会自动挤出同额私人投资。只要提高家庭储蓄比例，投资就一定增加。政策后 GDP 比此前低，所以公共采购没有产生正面作用。

完成四项任务：

1. 重建 GDP、私人储蓄与三部门余额。
2. 逐句区分会计错误、边界错误和缺少证据的因果判断。
3. 为“提高储蓄意愿”写出两个不同结果的机制。
4. 列出评价公共采购效果所需的反事实与资源证据。

<details>
<summary>综合作业参考答案与评分依据</summary>

GDP＝1,000，私人储蓄＝200，私人净贷出＝50；政府余额 −20，国外余额 −30，三者合计为零。简报把政府赤字直接等同境内私人净金融资产增加，遗漏了对外顺差；真实存量变化还要处理估值等因素。

存款增加 8 与储蓄不是同一概念。可能发生资产购买、借款、还本或部门内部转移，也不能把居民与整个私人部门混为一谈。

发债不因会计等额就自动挤出同额实际投资。需要说明购债者、融资条件、央行反应、实际资源和企业行为。提高储蓄比例也不保证投资增加：在投资固定、需求不足的模型中，收入可能下降；如果新的投资机会、信用和预期促使投资增加，收入则可能维持或提高。

政策后 GDP 下降不能单独判定政策无正面效果。要估计没有政策时的路径，并核对采购是否实际执行、是否对应当期生产、投入资源是否闲置、是否存在供给或进口约束，以及同期其他冲击。

评价标准不是支持哪种学派，而是账户一致、概念边界清楚、至少给出两个有条件的因果机制，并说明如何用证据区分。

</details>

第一篇到这里建立了共同语言。后续学习有效需求、财政乘数和 MMT 时，都可以用这套方法检查：哪一步是定义，哪一步是会计，哪一步加入了行为，哪一步才是政策判断。

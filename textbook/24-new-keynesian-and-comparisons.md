# 第 24 章　加入现代主流框架：新凯恩斯主义与分歧的分类

[上一章：增长、分配与执行](23-growth-distribution-and-implementation.md) · [目录](README.md) · [下一章：历史案例](25-historical-cases.md)

编写日期：2026-10-03。以下方程与数字是明确简化的教学模型，不是某一央行的预测系统。

## 1. 为什么必须加入第三个参照

如果把“主流理论”描述成银行先收储蓄才能放贷、政府永远不能有赤字、经济总会立即充分就业，再与 MMT 比较，比较对象已经失真。

第 8 章的 IS–LM 是战后教学模型。现代新凯恩斯主义通常把价格调整摩擦、前瞻预期和政策规则放进动态框架；它内部也包含不同家庭、金融摩擦和财政政策研究。本章学习一个最小框架，然后将争议分成账户、制度、行为、经验和价值五类。

先修：[IS–LM](08-is-lm-and-demand-management.md)、[通胀](20-inflation-and-policy-design.md)、[债务](21-debt-and-sustainability.md)。

## 2. 从静态交点到跨期选择

在最简新凯恩斯主义模型中，家庭比较今天与未来消费，企业并非随时无成本调整所有价格，央行通常以短期利率为工具。即使价格最终调整，短期需求变化仍可能改变实际产出。

一个常用的线性化动态需求关系是：

x_t = E_t(x_next) − σ[i_t − E_t(π_next) − r*_t] + d_t。

x 为产出缺口，i 为名义政策利率，π 为通胀率，r* 为与模型中基准产出相容的自然实际利率，σ > 0；d 是本章另加的需求扰动。E_t 表示利用当期信息形成的预期。

实际利率近似为 i − 预期通胀。实际利率高于 r*，倾向于压低当前相对未来的需求。预期未来收入改善，也可能提高今天的需求。上述关系来自特定跨期行为假设，不能由银行资产负债表直接推出。

这里的“自然产出”是某个模型在特定价格灵活条件下的参照。若存在垄断、外部性等扭曲，它不一定等于社会最优产出；r* 也不是央行可以直接观察的常数。统计机构估计的潜在 GDP、充分就业政策目标与模型自然产出，不能未经说明就当成同一概念。

## 3. 价格为何与预期有关

简化的新凯恩斯菲利普斯曲线写作：

π_t = βE_t(π_next) + κx_t + u_t。

β 是前瞻项系数，κ > 0 表示边际成本与缺口向价格的传导，u 是成本或加价冲击。严格微观模型中常先得到实际边际成本关系；把它写成产出缺口需要额外条件。

企业知道一部分价格可能持续多个时期，所以设价时考虑未来成本。这是“预期进入通胀”的一个机制，不等于任何通胀都由主观想法凭空产生。

这套三方程传统及其货币政策含义，可从 Clarida、Galí 与 Gertler 的原始综述入门；以下算例是本书重新构造的静态切片，并非其估计结果。[Clarida、Galí 与 Gertler，1999](https://people.ucsc.edu/~walshc/UCSC/105_f15/Readings/ClaridaGaliGertler_ScienceJEL1999.pdf)

## 4. 把央行反应写进同一个算例

为避免目标水平干扰，令 p 表示“通胀率偏离目标的百分点”，j 表示“名义利率偏离基准的百分点”。所有变量统一用百分点或产出百分比缺口。固定预期偏离为零，给定参数：

x = d − j；
p = 0.5x + u；
j = 1.5p + 0.5x。

第三式是教学用政策反应函数，不是现实央行机械执行的法律。将第二式代入第三式：

j = 1.25x + 1.5u；
2.25x = d − 1.5u。

先给需求冲击 d = 2，u = 0：

x = 0.8889，p = 0.4444，j = 1.1111。

如果央行保持 j = 0，同一个冲击会使 x = 2、p = 1。政策反应减弱了产出和价格变化，因此不能把“财政或私人需求冲击多大”与“央行如何回应”分开估计。

再给成本冲击 u = 1，d = 0：

x = −0.6667，p = 0.6667，j = 0.6667。

央行加息使需求低于参照产出，部分压住成本冲击带来的通胀，但造成产出损失。若要求当期 p = 0，则 x 必须为 −2；在本例需求式中，需要 j = 2。这个代价来自模型条件，不是“央行完全无法处理供给冲击”，也不是“应当不惜一切代价立即压回目标”。

## 5. 利率下限为什么改变政策组合

假设自然实际利率为 −3%，预期通胀为 1%。要使实际政策利率等于自然利率，名义利率应为 −2%。

若本例规定名义利率有效下限为 0%，实际利率只能降到约 −1%，仍比自然利率高 2 个百分点。即使央行已大幅降息，需求仍可能不足。这给财政扩张、前瞻指引或其他政策留下分析空间。

“有效下限”不是永远严格等于零；现实制度下曾出现负政策利率。本例的零下限只是设定。政策效果还取决于可信度、家庭反应、银行传导和未来财政安排。

因此，新凯恩斯主义模型完全可能得到“衰退时应扩大赤字”的结论。分歧常在财政何时有效、央行是否抵消、怎样退出，而非一方允许财政、另一方完全禁止。

## 6. 代表性家庭省略了什么

若所有家庭都能低成本借贷、拥有相同资产并平滑消费，收入分配和现金流的重要性可能被弱化。现实中，拥有住房但几乎没有现金的家庭，与持有大量流动资产的家庭，对一次转移支付或加息的反应可能不同。

异质性主体新凯恩斯主义模型（HANK）将家庭差异和不完全保险纳入框架。Kaplan、Moll 与 Violante 的研究重新讨论货币政策的直接替代效应及劳动收入等间接渠道。[Kaplan、Moll 与 Violante，2018](https://www.aeaweb.org/articles?id=10.1257/aer.20160042)

这说明“现代主流”不是单一的代表性家庭模型；但引入异质性也不自动解决根本不确定性、制度变迁或政治权力等全部问题。评价任何模型，应问它为了处理某个问题保留了什么、舍弃了什么。

## 7. MMT 与新凯恩斯主义真正需要比较的地方

| 层面 | 可比较的问题 | 合适的检验 |
| --- | --- | --- |
| 会计 | 银行贷款是否同步创造存款 | 逐笔账表，核对部门边界 |
| 法律制度 | 财政账户能否透支、谁能授权支出 | 适用日期的法律与操作规则 |
| 行为机制 | 加息的支出抑制是否超过利息收入刺激 | 部门现金流、债务重定价与消费反应 |
| 宏观闭合 | 利率路径由什么规则决定，财政怎样响应 | 明确完整政策反应而非孤立方程 |
| 劳动市场 | 一般需求刺激与就业保障怎样影响岗位和工资 | 净就业、流动、替代与价格证据 |
| 价值目标 | 应怎样权衡失业、通胀、分配和公共服务 | 公开目标与代价，接受公共讨论 |

MMT 常强调货币发行者的实际资源约束、财政稳定功能与就业保障；新凯恩斯主义常用动态均衡与政策规则组织分析。它们并不因此拥有互不相容的每一条账户关系。

较深的争议涉及：自然利率作为分析中心有多大用处；失业缓冲与就业缓冲哪种制度更好；财政调整能否及时、可靠地稳定名义需求；央行利率政策的净效果如何；预算限制作为跨期均衡条件与作为日常付款程序应怎样区分。

“政府预算约束”在模型里可能是存量流量恒等式、偿付条件，或排除某些债务路径的均衡限制；讨论时要指明是哪一个。MMT 对特定融资叙述的批评，不会取消恒等式；某模型对未来税收的假设，也不能直接冒充今天财政支付的法律程序。

## 8. 一个有用的分歧检验顺序

先让两方在同一机构边界下记录同一笔交易。账户仍不同，优先找错误。账户相同而结论不同，列出消费、投资、价格、汇率与政策反应假设。随后比较证据能否区分这些行为假设。最后，若双方对后果判断相近而选择不同，检查是否采用了不同社会目标。

这种顺序允许得到细致结论：某作者的账户说明正确，但政策推断证据不足；另一模型的机制有用，但遗漏了特定制度；某种政策在同样数据下得到不同评价，因为分配权重不同。无需宣布一个学派对所有问题获胜。

## 9. 练习与参考答案

### 练习 1：实际利率

名义利率 4%，预期通胀 2.5%，自然实际利率 0.5%。按近似公式，实际利率高出自然利率多少？

<details><summary>参考答案</summary>

实际利率约 1.5%，高出 1 个百分点。若采用精确费雪关系，则为 1.04/1.025 − 1 ≈ 1.463%；线性模型使用近似值，应注明口径。
</details>

### 练习 2：需求冲击

使用第 4 节三式，d = 4.5，u = 0，求 x、p、j。

<details><summary>参考答案</summary>

x = 4.5/2.25 = 2，p = 1，j = 2.5。代回需求式：4.5 − 2.5 = 2。
</details>

### 练习 3：成本冲击

仍用三式，d = 0，u = 1.5，求三个变量。

<details><summary>参考答案</summary>

x = −2.25/2.25 = −1，p = −0.5 + 1.5 = 1，j = 1.5 − 0.5 = 1。通胀偏高与负缺口可以同时出现。
</details>

### 练习 4：下限约束

自然实际利率 −2%，预期通胀 0.5%，名义利率下限 0%。所需名义利率与实际利率缺口是多少？

<details><summary>参考答案</summary>

所需名义利率约 −1.5%。下限下实际利率约 −0.5%，比自然利率高 1.5 个百分点，仍有需求收缩压力。
</details>

### 练习 5：分类而不是站队

“财政支出增加准备金，所以加息必然提高总需求。”论证跨越了哪些层次？

<details><summary>参考答案</summary>

先要限定财政支付与同期税收、发债及央行操作，才能说准备金净变化。即使账户判断成立，加息的总需求效果仍涉及借款成本、债权人收入、资产价格、汇率和预期；不能由准备金账户直接推出行为结论。
</details>

### 练习 6：可检验的反对意见

如何把“就业保障没有效率”改写成可检验命题？

<details><summary>参考答案</summary>

可提出：在相同地区与预算口径下，加入项目者的净就业、后续市场就业、服务产出及单位管理成本，相对可比的转移支付或培训方案没有改善。随后规定对照方法、观察期和外溢处理。“效率”的福利权重仍须说明。
</details>

## 10. 第五篇综合作业：同一个冲击的三层评估

假想经济体出现进口能源成本冲击 u = 1，同时外需下降，形成 d = −0.75。沿用第 4 节模型；其参数仅用于课堂比较。

1. 按原政策规则求 x、p、j。
2. 一项财政政策将 d 提高 1.5，求新结果。
3. 为什么不能仅据第二步支持所有财政支出？
4. 加入就业保障方案时，还需要哪些模型外资料？

<details><summary>综合作业参考推理</summary>

初始 x = (−0.75 − 1.5)/2.25 = −1，p = 0.5，j = 0.25：需求疲弱与输入成本上升同时存在。

政策后 d = 0.75，x = −1/3，p = 5/6 ≈ 0.8333，j = 13/12 ≈ 1.0833。产出缺口改善，但通胀偏离扩大，央行也提高利率。这里的财政扰动 d 不是预算金额，二者之间还需乘数与制度映射。

这只是给定政策规则和固定预期下的比较。若政策降低能源成本 u、增加供给，或央行改变反应，结果不同；若项目迟迟不能交付，d 也未必按设定上升。

就业保障的评估还需劳动者技能与地区、报名人数、岗位工资、材料进口、管理容量、与私人岗位的替代、净预算成本以及服务质量。不能只凭一个总量缺口计算应设置多少具体岗位。
</details>

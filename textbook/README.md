# 凯恩斯主义与现代货币理论：从有效需求到财政货币制度

本书要让读者能够用同一组事实和账户比较不同理论：解释失业与通胀，追踪财政和货币操作，识别政策的前提、作用机制与约束，并说明什么证据会改变判断。

“传统凯恩斯主义”主要指凯恩斯原始理论及战后凯恩斯主义综合体系。涉及特定模型时明确写出假设，不将其推广成所有凯恩斯主义者的共同立场。MMT 的制度描述、因果论证和政策建议分别评价；不同作者的观点注明归属。

## 怎样阅读与检验理解

基础公式只要求四则运算与简单代数；进阶论证单列。每章用问题、机制、算例和对照情景形成主线，真实资料与教学假设明确区分。练习不仅检验计算，也要求读者提出替代解释、指出缺少的证据并说明适用边界。

比较时依次检查：问题是否相同，制度前提是否相同，账户是否一致，行为假设在哪里不同，结论是否真的不同，什么证据可以判断。

# 附录 B　公式、符号与逐步推导

[上一项：学派地图](appendix-a-schools-and-people.md) · [目录](README.md) · [下一项：账户练习册](appendix-c-accounting-workbook.md)

编写日期：2026-10-03。所有公式必须连同口径使用。以下不是彼此可以无条件联立的一套模型；每一组都列出自己的条件。

## 1. 统一符号时先检查单位

| 符号 | 本附录含义 | 常见误用 |
| --- | --- | --- |
| Y | 同一期间产出或收入，具体组别注明 | 名义、实际与潜在产出混用 |
| C、I、G | 消费、私人投资、政府购买流量 | 把全部预算支出都记作 G |
| T | 税收，若扣除转移则明确叫净税收 | 公式用净税，数据却用税收毛额 |
| X、M | 出口、进口 | 把这里的 M 当货币供应量 |
| S | 私人储蓄流量 | 存款存量、私人净金融资产 |
| CA | 经常账户余额，顺差为正 | 未经调整等同海关货物顺差 |
| D、PD | 总赤字、基本赤字，赤字为正 | 与采用盈余为正的数据直接混接 |
| B、b | 名义债务余额、债务与名义 GDP 之比 | 不说明债务部门范围 |
| i、g | 名义利率、名义 GDP 增长率 | 用实际增长率配名义利率 |
| e | 本币/单位外币 | 将 e 上升误叫本币升值 |

利率 3% 在普通代数里用 0.03；若新凯恩斯主义示例明确按百分点写方程，3% 才可能记作 3。两种记法不能在同一计算中悄悄切换。

## 2. 部门余额：先做最简单的推导

假设没有净要素收入和跨境转移，没有折旧和资本转移，政府购买为 G，税收为 T：

Y = C + I + G + X − M；
S = Y − T − C。

把第一式代入第二式：

S = I + G − T + X − M；
S − I = (G − T) + (X − M)。

若定义 D = G − T，且在这些简化条件下 CA = X − M：

私人净借出 = D + CA。

另一种写法是：

私人净借出 + 政府净借出 + 国外部门净借出 = 0。

例：政府赤字 50、经常账户逆差 30，则私人净借出 20。它不是“所有家庭储蓄总额等于 20”，因为私人部门还包括企业，S − I 又不同于 S。

一般统计体系中，要改用相应国民可支配收入并处理跨境收入和转移；完整净借出还涉及资本账户、资本转移和非生产非金融资产取得等调整。官方部门金融余额与国民账户余额也可能存在统计差异。不要为了维持课堂简式，删掉真实表中的调整项。

详见[第 4 章](04-identities-behavior-and-causality.md)与[第 22 章](22-open-economy-and-external-constraints.md)。

## 3. 开放经济乘数：每一项泄漏从哪里来

设：

C = C0 + c(Y − T)，T = T0 + tY；
I、G、X 外生，M = M0 + mY。

其中 0 < c < 1，t 是比例税率，m 是边际进口倾向。代入产品市场：

Y = C0 − cT0 + c(1 − t)Y + I + G + X − M0 − mY。

移项：

[1 − c(1 − t) + m]Y = C0 − cT0 + I + G + X − M0。

令 A 为右侧自主需求，q = 1 − c(1 − t) + m，则：

Y = A/q；
政府购买乘数 = 1/q；
定额税收乘数 = −c/q。

若政府向家庭新增转移 TR，并令可支配收入为 Y − T + TR，则转移乘数为 c/q。这里给付对象被设为具有同一消费倾向 c，且不改变投资、供给和利率。

例：c = 0.75、t = 0.2、m = 0.1，q = 0.5，所以购买乘数 2、定额税收乘数 −1.5、转移乘数 1.5。

**平衡预算政策：**ΔG = ΔT0 = 10 时，ΔY = (1 − c) × 10/q = 5。平衡预算乘数等于 1 只在更特定条件下成立，例如无比例税与进口、无其他反馈的简单模型。本例自动税收还会随 ΔY 变化，因此事后预算余额也不能只看定额税与购买恰好相等。

若还设投资 I = I0 − a i，利率反应 i = i0 + hY，则分母增加 ah，乘数下降。这里 a、h 的单位必须匹配。此式是静态简化，不是第 24 章完整前瞻模型。

## 4. 财政现金、净融资与总发行

在忽略其他调整的现金模型中：

期末现金 − 期初现金 = 收入 − 非融资支出 + 总发行 − 到期还本。

令现金缺口 = 非融资支出 − 收入，则：

净融资 = 现金缺口 + 现金余额增加；
总发行 = 净融资 + 到期还本。

例：缺口 40、现金增加 10、还本 200，净融资 50、总发行 250。国债本金偿还不能再计入非融资支出，否则同一融资交易被重复计入赤字。

实际预算与现金口径可能因信贷项目、应计利息、估值和其他项目而不同，必须加入调节表。见[第 17 章](17-why-governments-issue-bonds.md)。

## 5. 债务动态：分母不能漏掉

先固定政府债务范围，假设债务按名义余额计量，基本赤字完全用新债融资：

B_t = (1 + i_t)B_prev + PD_t + SF_t。

SF 是不在基本收支和已列利息中的存量流量调整；本式暂不含货币融资的单独分项。若有央行负债融资或现金资产变化，需要相应扩展，不可机械套用。

名义 GDP 为 Y_t = (1 + g_t)Y_prev。定义：

b_t = B_t/Y_t；
d_t = PD_t/Y_t；
s_t = SF_t/Y_t。

除以当期名义 GDP：

b_t = [(1 + i_t)/(1 + g_t)]b_prev + d_t + s_t。

因此：

Δb = [(i_t − g_t)/(1 + g_t)]b_prev + d_t + s_t。

若 s = 0，稳定债务率所容许的基本赤字率为：

d_stable = [(g − i)/(1 + g)]b_prev。

例：b_prev = 100%、i = 3%、g = 5%，稳定基本赤字率约 1.9048%。这里 d 以当期 GDP 为分母。若某教材用上期 GDP，公式形式会不同，不能只比较表面系数。

实际增长率 g_real 与价格增长率 π 的精确关系是：

1 + g_nominal = (1 + g_real)(1 + π)。

实际增长 2%、价格增长 3%，名义增长为 5.06%，不是精确的 5%。

## 6. 利率、债券与汇率

**费雪关系：**1 + r = (1 + i)/(1 + π)。事前分析用预期价格变化，但预期下精确求值还可能涉及不确定性与风险；常用线性近似 r ≈ i − Eπ。

**一期间债券：**明年确定支付 F，收益率为 i，则今天价格 P = F/(1 + i)。F = 100，i 从 5% 到 10%，价格从约 95.24 降至 90.91。长期债券是各期现金流折现之和，还可能有信用与流动性风险。

**外币负债折算：**净外币负债为 L* − A*，则本币折算值为 e(L* − A*)。外币债 50、外币资产 20，e 从 5 到 6，净负债本币值从 150 升到 180。忽略价格和现金流变化时，权益损失 30。

**外币投资本币回报：**

1 + R_home = (1 + i_foreign) × e_next/e_now。

国外利率 3%、e 从 7 到 7.14，本币回报为 1.03 × 1.02 − 1 = 5.06%。若未来 e 未知，这是有汇率风险的回报，不能当作保证收益。使用远期合约讨论有担保利率平价，还需交易成本、信用与资产负债表约束，见[第 22 章](22-open-economy-and-external-constraints.md)。

## 7. 就业保障的三个不同计算

**失业率：**

u = 失业人数 / 劳动力人数。

从非劳动力进入岗位的人，同时扩大就业和分母。原劳动力 1,000、就业 900、失业 100；70 名失业者与 10 名原非劳动力参加，就业变 980、劳动力 1,010、失业 30，失业率约 2.97%。

**项目毛成本：**

毛成本 = 人数 ×（工资 + 人均支持成本）+ 固定管理成本。

**相对明确反事实的净预算成本：**

净成本 = 毛成本 − 被替代的原有给付 − 新增税收 + 其他新增财政成本。

减少原给付必须确实发生；不能假定每个参加者都原来领取同额救济。税收是财政回流，不等于实际资源被免费创造。

净就业还需扣除无项目时会就业者和被替代岗位，处理间接就业。报名人数、净就业与净成本是三种不同统计。

## 8. 资本、项目与价格

资本积累：K_next = (1 − δ)K + I。

净现值：NPV = −初始成本 + Σ[未来净收益_t/(1 + r)^t] + 折现残值。实际收益配实际折现率，名义收益配名义折现率。社会收益不等于现金收费。

容量约束下的单部门教学价格：若给定名义支出 E、实际供给固定为 Q，且市场完全以价格出清，则 P = E/Q。这只在所述调整机制下成立；存在库存、排队、行政价格或进口时，需要改模型。

多部门按基期价格计量的实际产出 Y_real 与名义产出 Y_nominal 之比为相应隐含价格指标。它不是自动等于 CPI，消费者篮子、权重和进口处理可能不同。

## 9. 新凯恩斯主义教学切片

第 24 章原模型包含前瞻项；固定这些预期偏离后，示例为：

x = d − j；
p = 0.5x + u；
j = 1.5p + 0.5x。

联立得到：

x = (d − 1.5u)/2.25；
p = 0.5x + u；
j = d − x。

其中 x 为百分比缺口，p 和 j 为相对基准的百分点，u 为成本冲击。参数和预期固定才可这样计算；不能把 d 直接当成财政支出的货币金额。完整含义见[第 24 章](24-new-keynesian-and-comparisons.md)。

## 10. 计算前的四行说明

每次应用公式，先写“部门与期间”“单位与价格口径”“不变条件”“怎样闭合行为”。之后先代回恒等式，再解释政策含义。若公式算得正确但无法写清这四行，结论仍可能用错对象。

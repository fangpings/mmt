编写日期：2026-10-03。本附录按当前相邻目录中的实际文件建立链接：本书解释理论与比较方法，美国、中国教材补充制度、数据生产和传导细节。链接采用本地相对路径，三套目录保持相邻时可直接阅读。

## 1. 三套教材各自解决什么问题

本书从“不同理论为何得到不同政策判断”出发；[美国教材](../../us-econ/textbook/README.md)和[中国教材](../../cn-econ/textbook/README.md)帮助读者把判断落实到具体指标、机构与市场。

最有效的次序是：先学一个机制，再到对应国家找它的可观测变量，最后回本书做政策比较。不能将理论公式里的变量与新闻里同名的统计直接对接，例如 G 与预算支出、M 与货币量、S 与存款、赤字与债券发行。

## 3. 四条专题路线

### 路线一：看到赤字新闻，先不下结论

先读本书第 4、14、21 章，再读美国第 14 章或中国第 22—24 章。做一张“预算、现金、融资、需求”四栏表。

用美国资料时，先确定联邦财政年度，再区分 receipts、outlays、到期还本和现金余额。用中国资料时，先确定哪本预算、中央本级还是全国、是否包含转移，再列调入资金和结余。最终只在一致范围内比较政策变化。

输出应是：“这个赤字变化有多少来自周期，有多少来自法律政策或确认时点；哪些支出已转成当期国内购买。”不能只写“赤字大，所以刺激强”。

### 路线二：看到货币数量增加，追踪交易

先读本书第 12、15、18 章与附录 C，再进入两国银行与货币市场章节。选择一笔贷款、一笔财政支付和一笔央行购债，分别画四方账户。

随后查观测量属于哪一层：公众持有的存款、银行在央行的准备金、某种货币统计、信贷融资总额，还是资金市场交易。中国社融的组成与范围可继续读[18 社会融资](../../cn-econ/textbook/18-social-financing.md)；美国金融部门关系可读[金融系统地图](../../us-econ/textbook/financial-system-map.md)。

输出应说明“谁的资产和谁的负债增加”，再讨论消费、投资或资产配置。不要用一个总量替代全部交易路径。

### 路线三：看到物价上涨，先找瓶颈位置

先读本书第 9、20、22、24 章，再进入两国价格与外汇章节。将物价变化分解为能源、商品、住房或其他服务等适用分项；同时观察劳动、产能、交付、进口价格和预期。

如果主张财政收缩，要说明减少哪类购买力、会影响哪些资源；如果主张补贴或供给投资，要说明成本谁承担、何时增加供给；如果主张加息，要说明债务重定价和需求渠道。

输出不是“需求型”或“供给型”一个词，而是一条带时间顺序的机制与一个替代解释。

### 路线四：看到地方风险，别直接套用货币主权

先读本书第 13、21、27 章，再读美国市政融资或中国地方债与土地财政。列出法律发行人、合同币种、到期分布、可用现金、运营收入、税收或预算支持和或有责任。

国有资产、土地账面价值和上级潜在支持不能未经验证全部按现金计入。债务置换降低利率或拉长期限后，仍需检查最终现金来源。

输出应同时给出单体现金表与明确边界的合并风险表，解释哪些内部债权被抵销，哪些外部负担仍然存在。

## 4. 一份可以复用的跨国资料卡

| 字段 | 填写要求 |
| --- | --- |
| 经济问题 | 例如消费不足、材料瓶颈或地方付款压力 |
| 理论机制 | 使用哪一章的哪条关系 |
| 主体边界 | 联邦、中央本级、全国政府、银行或企业 |
| 统计变量 | 原文名称，避免凭中文简称猜测 |
| 期间与版本 | 月、季、财政年或日历年；发布时间与修订版 |
| 单位与价格 | 本币、占 GDP 比例；名义或实际 |
| 制度前提 | 权限、币种、兑付与融资安排 |
| 不可比项目 | 转移、预算间往来、到期还本、估值等 |
| 待检验假设 | 将哪项行为反应暂设为多少 |
| 替代解释 | 还有什么变化能产生同一观测结果 |

例如，“美国联邦赤字”与“中国全国一般公共预算赤字”可以放在两张资料卡上展示，但没有覆盖与确认口径调整，就不能直接命名为完全可比的财政冲击。用占 GDP 比例缩放只解决规模，不解决概念。

## 5. 联读练习与答案

选一项财政扩张新闻，分别写以下三句话：

1. 这项措施在行政上走到了哪一步？
2. 本期怎样影响资产负债表，是否增加了某个部门的还款义务？
3. 本期国内需求与下一期供给分别通过什么机制变化？

参考判断：发债公告可能只意味着未来融资安排；贷款发放会增加借款义务；偿还旧债可能改变期限和利息；新增采购须核对交付与进口；转移支付须观察消费与偿债。若三句话都只写“投放了资金”，说明还没有完成传导分析。

最后回到[第 28 章](28-policy-design-workshop.md)，用真实国家的机构和数据替换虚构设定，但保留同一比较纪律：账户必须对得上，行为需要证据，价值目标应公开，结论有明确适用边界。
